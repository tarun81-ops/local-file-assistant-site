What it does

Built for questions about your own documents

Find
Finds files by name or content in the folders and drives you allow. It copes with misspelled names and names typed in Hinglish.
Answer
Every answer lists the file and page it used. A claim that is not in the cited file is marked as not verified.
Your documents
Asked for your own marksheet, it checks the name on the file, so someone else's is not shown as yours. Totals and percentages are calculated by code, not guessed.
Workspaces
Keep separate sets of folders, each with its own chats and answer style.
Files only
Checks each answer against your files and says so when it cannot back it with one, instead of answering from general knowledge.
Drop a file
Drop a PDF or an image on the chat to ask about it. It is read for that answer and added to your index only if you choose Keep.
Plug-in tools
Add local MCP servers as tools. A tool that looks like it changes things or sends data asks you first.
You approve changes
Tidying up files is a proposal you approve, and removed files go to the Recycle Bin.
Model picker
See the models on your PC with their size and expected memory use, and download or remove them. It never switches model by itself.
Updates
Checks for a new version once a day, tells you when one is ready, and restarts only when you click. You can switch the check off.
Privacy

What stays on your PC, and the few times it goes online

Stays on your PC

  • Your files and the search index
  • Your chats and settings
  • The model that writes the answers

Goes online only when you let it

  • Downloading a model, when you click Download
  • The daily update check, which you can switch off in Settings
  • An optional other model server. It is off by default, and a server that is not on your PC needs https and a second confirmation.

Never

  • No account to create
  • No telemetry or usage tracking
  • No files uploaded to us
Get started

From download to first answer

  1. Download and install

    Run the installer. If Windows warns you, choose More info, then Run anyway.

  2. Let the wizard set up

    It checks the engine and downloads the model, with a progress bar you can cancel.

  3. Choose what it may read

    Pick the folders or drives. You can start with names only and widen it later.

  4. Ask a question

    Try one of the example questions, then ask about your own files.

Questions

Before you install

Does it need the internet?

Only to download a model and to check for updates. After that it answers offline.

How accurate is a small model?

It can still make mistakes. That is why each answer shows the file and page it used, and why a claim that is not in the file is marked. Open the source when the answer matters. Files only mode adds a stricter check.

Will it change or delete my files?

Only after you approve a proposal. Removed files go to the Recycle Bin. Reading your files never changes them.

Which build should I pick?

Pick OpenVINO on an Intel PC, especially one with a Core Ultra processor, because it can use the graphics chip or the NPU. Pick Ollama if you already run Ollama or your PC does not have Intel graphics.

Does it work on Mac or Linux?

Not yet. The installers are for Windows 11.

How do I update it?

It checks once a day and shows "Update ready, restart?". Nothing installs until you click. The check can be switched off in Settings.
